Why this page existsWhy a bench

  1. They set the bar.ESCAPE VELOCITY is the strongest music video made with Claude that this site has seen, and every film after it here comes from the same director with the same star. LAST LIGHT and whatever follows it get measured against them, not against nothing.
  2. She sings.In ESCAPE VELOCITY, Claudia lip-syncs the real vocal: every moving shot was generated from a still and the exact slice of the song it sits under. LAST LIGHT has no people on screen, so its pipeline never had to solve a singing character. This is what solving it looks like.
  3. The method is public.ESCAPE VELOCITY's making-of is published in full: every prompt, the director's notes and the agent prompts. One director, about 50 messages, about 19 hours. A bench is only useful if you can see how the reference was made.
  4. One character, dated runs.The same idol, film after film, with the same spark in her hair. Like the editions on this site's home page, each new film is a dated run of the same test, so the change between runs is the thing to watch.

Every film here is anabology's work, shown with credit and a link back. Nothing on this page was made by this site except the page. Streams are 720p.
