Force Multiplier 02 · Reading

Obsidian Reader

Read a page clean, mark what mattered, and keep it as a plain file that you, your notes and your tools can all find again.

Bottom line

Reader is the reading mode inside Obsidian Web Clipper, a free browser extension. The multiplier is not the clean page. It is that what you read ends up as a text file on your own disk, with its source and date attached, where a search, a link or an AI agent can reach it.

1 · In plain wordsA photocopier with a highlighter

Picture reading a magazine at a desk with a photocopier beside it. You tear out the ads, read the article, run a highlighter over the three lines that matter, and file the copy in a labelled folder with the date and where it came from written on top.

Reader and the clipper do that for web pages. Reader removes the clutter. The highlighter marks the lines. Clipping files the copy, and it writes the label for you.

A bookmark only remembers where a page was. This keeps what it said, including after the page changes or disappears.

2 · The mechanismFour moves, one file

Reader
Strips the page down to the article and shows the title, author, date and source. Long pieces get an outline in a sidebar, code blocks get syntax colouring, and footnotes open in place. You set the font, size, line height, line width and a light or dark look.
Highlighter
Marks selected text, images or whole elements. Highlights are saved, so they are still there when you return to the page.
Clip
The Add to Obsidian button saves the page into the vault and folder you choose. By default it keeps the main article. If you selected text first, it keeps the selection.
The file
Markdown, with a short block of properties at the top. Obsidian reads it, and so does any text editor, search tool or script.

What a clipping looks like

This is the shape of every clipped page: seven properties, then the text. Highlights arrive wrapped in double equals signs.

---
title: "Two Stories About the Beginning | Sean Sooch"
source: "https://seansooch.dev/two-stories/"
author:
  - "[[Sean Sooch]]"
published: 2026-09-16
created: 2026-10-09
description: "The Big Bang and a generated origin are the same kind of story: a starting condition plus a rule, with the evidence only ever reaching the rule."
tags:
  - "clippings"
---
The page text, as Markdown. Headings, links and images survive.

==A line you highlighted before clipping.==

Those seven lines are why the folder stays useful. source lets you cite it. published and created tell you how old the claim is and when you met it. tags lets you pull every clipping at once.

Why it multiplies

The vault is a folder of text files. That sounds like a detail and it is the whole point. A note you can only open inside one app helps one person, one page at a time. A folder of dated, sourced text files can be searched in one pass, linked into your own notes, and read by an AI agent that has access to the folder, so a question like "what have I saved about this, and who said it" gets answered from your own reading with the sources attached.

The vault behind this site holds 56 clipped pages, saved between April and September 2026, and every one carries the same seven properties. One is a recorded lecture saved together with its transcript. None of them contains a highlight yet, which is the honest state of most vaults: clipping is the easy half.

3 · Set it upFive steps

  1. Install Obsidian and the Web Clipper extension. The clipper is offered for Chrome and other Chromium browsers, Firefox, Edge, and Safari on Mac, iPhone and iPad.
  2. Clip one page. Open the clipper with Cmd Shift O (Ctrl Shift O on Windows and Linux), pick the vault and folder at the bottom of the panel, and press Add to Obsidian. Quick clip, which skips the panel, is Opt Shift O or Alt Shift O.
  3. Make Reader one press away. Reader opens from the book icon in the panel, from the right-click menu, or from a shortcut you choose. In settings you can also make the toolbar button open Reader directly.
  4. Decide what highlights do. In the highlighter settings, choose whether a clip keeps the page with your highlights marked, keeps only the highlights, or ignores them. For long articles, only the highlights is usually the right default.
  5. Give your most-clipped site its own template. A template sets the folder, the tags and the properties for pages from one site, so threads land in one folder and papers in another without you filing anything.

There is also an optional feature called Interpreter that runs a prompt over the page as it is clipped, such as a three-line summary. It needs a model provider and usually an API key, and it sends the page text to that provider. It can be pointed at a model running on your own machine.

4 · What most people get wrongFive traps

  1. Clipping instead of reading. Saving a page feels like progress and teaches you nothing. If you would not highlight a single line, you probably do not need the page.
  2. Keeping everything. A vault with every page you opened is a second browser history. Search returns all of it and nothing says why you kept it. Keep the highlights, or one line in your own words at the top.
  3. Leaving highlights in the browser. Until you clip, highlights live in the extension. They can be exported, but the durable copy is the file in the vault.
  4. Treating a clipping as yours to republish. A clipped article is a personal copy of someone else's work. Keep it private, and share the link and your own notes.
  5. Trusting an old clipping. The file records the day the page was published and the day you saved it. Read both before you repeat what it says.

5 · Check yourselfThree questions

RecallWhere does a clipped page end up?
Show the answer

A file in your vault, which is a folder on your own disk. Obsidian's help page for the clipper says the extension does not collect your data or gather usage metrics.

Apply itYou are reading a 6,000 word article and three paragraphs matter. What should the clip keep?
Show the answer

Only the highlights. The source property still points at the full article if you need it, and the note you will actually reread is three paragraphs long. A bookmark keeps none of the text and breaks when the page moves.

What would breakSuppose clippings were saved inside the extension instead of as files. What is lost?
Show the answer

You could still read each one, one at a time, in one app. What goes is the multiplier: a plain file is reachable by every other tool you have, now and later, and a note locked in one program is not.
